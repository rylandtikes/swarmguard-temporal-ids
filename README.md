# SwarmGuard Temporal IDS

## Overview
This repository supports research for the paper:

> **Early Detection of Coordinated AI-Agent Campaigns Using Temporal Event Graphs**

The project investigates methods for detecting coordinated malicious activity across distributed systems and sensors.

The implementation and experimental design are still evolving, so the repository should remain flexible and avoid assuming a specific machine-learning model or detection architecture.
